# Privacy

WildHunt is local-first.

- Photos are read in the browser.
- Images are sent directly to the configured Ollama endpoint.
- There is no WildHunt image-upload backend in the MVP.
- No account is required.
- No analytics SDK is included.
- No cloud image storage is included.

A remote Ollama endpoint changes the trust boundary. Users should only configure endpoints they trust.

The project does not claim that local inference makes a device or operating system inherently secure; normal device security still applies.
